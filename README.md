## Selected Builds

### ⚡ [NexusLOB](https://github.com/Mike-here/NexusLOB)
A C++17 limit-order-book and price-time matching engine optimized around predictable memory access: preallocated order storage, intrusive FIFO queues, hierarchical price bitmaps, lock-free SPSC rings, and Linux `epoll`.

### ✦ [Autopilot Career Concierge](https://github.com/Mike-here/career-concierge-engine)
A multi-agent resume-tailoring system with Context Hunter, Resume Tailor, and ATS Critic agents, plus an SSE-powered Starlette dashboard.

### ◈ [Akuna Capital Trading Challenge](https://github.com/Mike-here/akuna-capital-trading-competition-26-)
A market-making bot for simulated binary options using dynamic-programming pricing, analytical probability models, inventory skew, and liability reserves.

### ✚ [Hospital Insurance Billing System](https://github.com/Mike-here/Insurance-Claims)
A team-built dashboard for hospital billing summaries, analytics, and exportable reports with a persistent SQLAlchemy data layer.
